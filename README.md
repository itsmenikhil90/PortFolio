# 🚀 Getting Started

Follow the steps below to run the portfolio locally.

## 1. Clone the Repository

```bash
git clone https://github.com/itsmenikhil90/PortFolio.git
```

## 2. Open the Project

```bash
cd PortFolio
```

## 3. Run the Website

Open:

```text
index.html
```

directly in your browser.

### Recommended Method

If you are using **Visual Studio Code**, install the **Live Server** extension.

Then:

```text
Right Click → index.html → Open with Live Server
```

The website will open in your default browser.

The website follows responsive web design principles to ensure a consistent experience across different devices.

* CSS Grid
* Media Queries
* Relative Units
* Responsive Typography

This allows the website to adapt to different screen sizes without compromising usability.
